# film Narrator Studio

V1 beta — Mainly 30-second promos and short-form narrated videos from reference photos, accessible URLs (including YouTube) or ideas. Choose 15/30/45/60/90 seconds and optional reference sections. Outputs use Orbit attachments; native downloads deferred. Exact image models are managed by connected tools. Physical fresh-user setup remains unverified.
